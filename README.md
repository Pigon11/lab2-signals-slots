# Лабораторная работа №2 — Сигналы-слоты в PyQt5

Конвертер длины между метрами, милями и футами. При изменении любого поля два других пересчитываются автоматически — демонстрация механизма сигналов-слотов в Qt.

## Принцип работы

- Пользователь вводит значение в **любое** из трёх полей.
- Срабатывает сигнал `textEdited` (встроенный сигнал `QLineEdit`).
- Метод-обработчик валидирует ввод и **эмитит собственный сигнал** из модуля `cl1`/`cl2`/`cl3`.
- Слот в `main.py` ловит сигнал и пересчитывает **два других поля** (поле-источник не трогается, чтобы курсор не прыгал).
- Флаг `self.updating` защищает от рекурсии.

## Единицы измерения

| Единица | Обозначение | В метрах |
|---------|-------------|----------|
| Метр | м | 1 |
| Миля | mi | 1609.344 |
| Фут | ft | 0.3048 |

## Архитектура

- `cl1.py` — сигнал для метров (`MetersSignal`)
- `cl2.py` — сигнал для миль (`MilesSignal`)
- `cl3.py` — сигнал для футов (`FeetSignal`)
- `main.py` — окно, слоты, логика пересчёта
